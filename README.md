## Coding Standards

This repository contains source code demonstrating the use of our common coding standards for Python.

## Computer Science Department Coding Standards

You can find a document detailing our coding standards [here](https://docs.google.com/document/d/1OcnMoKuHEiV5r-ibiAzVLrj3hHJaTxTyyGqnOzPwU4Q/edit?usp=sharing).

## PEP Standards

Generally, we follow Python’s [PEP-008: Style Guide for Python Code](https://peps.python.org/pep-0008/) and [PEP-257: Docstring Conventions](https://peps.python.org/pep-0257/).  Deviations and additions to PEP-008 and PEP-257 are outlined in the above document.
